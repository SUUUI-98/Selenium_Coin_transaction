## 1. 자동화 시나리오
   1. 웹 페이지 접속 
   2. 로그인 버튼 선택 
   3. QR 로그인(모바일 수동)
   4. 실시간 보유 자산 확인 후 로그 출력 
   5. My-> 내 자산 보기 포트폴리오&자산 확인  
   6. DOGE 5000원 시장가 매수 
   7. 체결 목록 확인 후 출력
   8. DOGE 전량 시장가 매도 
   9. 실시간 보유 자산 확인 후 로그 출력




## 2. 사전조건 
   1. 회원 계좌 인증 완료된 회원
   2. 계좌 잔액 1만원 이상 보유



## 3. 프로젝트 학습 목표 
   1. Selenium 을 사용한 테스트 자동화 학습과 파이썬 학습
   2. DOM 요소 분석 학습
